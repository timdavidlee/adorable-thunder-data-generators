# List of Enterprise like Data Flows


These are the following

- Order-to-Cash (O2C) — quote, order, fulfill, invoice, collect, cash application
- Record-to-Report (R2R) — GL postings, journal entries, reconciliations, consolidations, close
- Acquire-to-Retire (A2R) — fixed asset lifecycle, depreciation, disposals
- Budget-to-Report (B2R) — planning, forecasting, variance analysis
- Plan-to-Produce (P2P) / Make-to-Stock — demand planning, MRP, production orders, BOMs, work orders
- Forecast-to-Stock(F2S) — demand sensing, inventory replenishment, safety stock
- Warehouse Management(WM) — receiving, putaway, picking, packing, shipping, cycle counts
- Transportation & Logistics(TL) — load planning, shipment tracking, freight audit, customs
- Returns / Reverse Logistics (RMA) — returns authorization, inspection, refund/restock
- Lead-to-Opportunity / Lead-to-Cash (L2O) — marketing leads, qualification, pipeline, contracts
- Campaign-to-Conversion (C2C) — marketing automation, attribution, engagement events
- Subscription / Quote-to-Cash (Q2C) — recurring billing, usage metering, renewals, churn
