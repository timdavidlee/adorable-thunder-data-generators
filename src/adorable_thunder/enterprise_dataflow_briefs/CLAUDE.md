# enterprise_dataflow_briefs

Shared reference briefs for all supported enterprise data flows. Each brief defines records, business rules, realism benchmarks, and applicable field generators for one flow.

Both `make/` (generation) and `scrutinize/` (realism evaluation) treat these as the authoritative source of truth. Other CLAUDE.md files import this file rather than individual briefs.
